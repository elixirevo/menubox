# MenuBox 1.4.1

This patch fixes a crash in menu bar discovery and improves hiding failures on macOS 27.

- Handles duplicate and invalid process IDs without terminating MenuBox. Conflicting process ownership is excluded from menu routing and hiding.
- Excludes MenuBarAgent popups and disconnected display windows from menu bar planning.
- Retries temporarily missing app visibility records while macOS registers newly launched apps.
- Defers status-item repair during sleep, hidden-layout verification, native menu interactions and Command-drag. Display changes and interrupted observations require fresh confirmation before repair.
- Always displays hiding failures in a readable, dismissible message, including when Box UI alerts are disabled. Background inventory updates no longer erase the error.
- Explains marker overlap, missing controls and items spanning both sides of the marker. Unsafe layouts and unsupported system controls still require correction before the section can hide.

중복 프로세스 ID로 앱이 종료되는 문제를 수정했습니다. macOS 27의 일시적인 배치·앱 등록 변화에 대한 처리를 개선하고, 숨김 실패 시 알림 설정과 관계없이 원인과 조치 안내를 표시합니다.
