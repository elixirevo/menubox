# MenuBox 1.4.2

This update fixes hiding independent Apple app icons on macOS 27, including Passwords.

- Uses menu bar ownership records instead of treating every `com.apple.*` app as a system control. Passwords now uses its existing application record without a Passwords-specific exception.
- Applies the same routing to icons that appear while the section is hidden.
- Allows independently identified Apple status items to use temporary menu placement and restoration in Box UI.
- Keeps individual system-control adapters and prevents hiding shared system hosts as whole applications. Missing, ambiguous or shared ownership still blocks unsafe changes.

macOS 27에서 암호 앱 등 독립적인 Apple 앱의 메뉴 막대 아이콘을 숨길 수 있도록 개선했습니다. 앱 이름별 예외 목록 대신 실제 소유 기록을 확인하며, 암호 아이콘의 숨김·복원과 오른쪽 시스템 컨트롤 유지를 실제 Mac에서 확인했습니다.

## Known issue

The relative order of icons and the MenuBox marker can change across MenuBox restarts. An icon that ends up to the right of the marker remains visible. This release does not fix that placement issue; Command-drag affected icons back to the intended side of the marker.
