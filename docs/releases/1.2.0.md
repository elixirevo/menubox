# MenuBox 1.2.0

StatusBox is now **MenuBox**. This release provides separate Apple Silicon and Intel builds, signed with Developer ID and notarized by Apple.

## Changes

- MenuBox branding across the app, GitHub repository, and Homebrew cask.
- Improved menu bar hiding on macOS 27, including recovery after sleep and display changes.
- More reliable native menus in Box UI, including dynamic menus behind the notch and custom popups that remain open until dismissed.
- Preserved Box inventory across partial scans and more consistent settings and permission setup.
- A new Sparkle signing key and signed update feed for MenuBox 1.2 and later.
- Imports saved StatusBox settings and menu bar positions on first launch.

## Upgrading from StatusBox

**This upgrade requires a one-time installation via Homebrew or DMG.** The previous Sparkle private key is unavailable, and StatusBox 1.1 was ad-hoc signed. Its updater cannot securely install a release signed with the new key. StatusBox 1.1's update checker instead links to this release page; StatusBox 1.0 has no built-in updater.

For Homebrew installations, quit StatusBox, then run:

```sh
brew update
brew upgrade --cask elixirevo/tap/menubox
```

The tap includes the `status-box` → `menubox` rename mapping. If Homebrew has not migrated the old token yet, run `brew migrate --cask status-box`, then repeat the upgrade command.

For manual installations, quit StatusBox, download the DMG for your Mac, and drag **MenuBox.app** into Applications. Open MenuBox and confirm your settings, then remove the old StatusBox app. Disable the old StatusBox login item and enable MenuBox's Launch at Login again if needed. Because the bundle identifier has changed, grant MenuBox Accessibility and, on macOS 27, Full Disk Access in its Permissions settings.

Future updates from MenuBox 1.2 use the new built-in updater. Check for updates from the menu opened by right-clicking the tape marker.

기존 StatusBox 사용자는 이번 한 번 Homebrew 또는 DMG로 MenuBox를 설치해 주세요. 기존 설정은 첫 실행 시 가져오며, 접근성·전체 디스크 접근 권한과 로그인 시 실행 설정을 다시 확인해야 합니다. MenuBox 1.2부터는 새 서명 키로 앱 내 업데이트가 제공됩니다.
