# MenuBox 1.5.6

MenuBox 1.5.6 fixes a false menu bar overlap error on macOS 27 and adds Korean and English error messages.

- Fixes hiding failures when macOS reports duplicate menu bars and one contains icons with zero width. MenuBox now prefers the observation with valid icon sizes and positions.
- Distinguishes unreadable icon positions from actual overlapping icons, so the error explains the appropriate next step.
- Uses the selected app language for hiding, restoration, permissions and menu-opening errors, including the error panel title and confirmation button. Language changes take effect after restarting MenuBox.

## Known issue

The relative order of icons and the MenuBox marker can still change across app restarts or status-item re-registration. Icons to the right of the marker remain visible. Command-drag affected icons back to the intended side of the marker.
