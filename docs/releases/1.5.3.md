# MenuBox 1.5.3

MenuBox 1.5.3 updates app-specific settings to match MacAppEssentials and fixes first-time login-item registration.

- Renames **Settings → Display** to **Features** and uses a sky-blue monitor icon.
- Keeps auto-hide, Box UI, click actions and menu bar icon controls together, preserving existing preferences.
- Updates the Korean and English onboarding guide to use the new tab name.
- Allows **Launch at Login** to be enabled when macOS has no registration record yet. Registration still happens only after the user enables it; failures can be retried and pending system approval remains visible.

**설정 → 표시**를 **기능**으로 변경하고 하늘색 모니터 아이콘을 적용했습니다. 자동 숨김·박스 아이콘·클릭 동작 등 기존 설정값은 유지되며, 온보딩의 한국어·영어 안내도 새 탭 이름에 맞췄습니다. macOS에 아직 로그인 항목 기록이 없는 경우에도 **로그인 시 실행**을 켤 수 있도록 수정했습니다. 등록은 사용자가 켰을 때만 수행하며, 실패 시 재시도와 시스템 승인 대기 상태를 안내합니다.

## Known issue

The relative order of icons and the MenuBox marker can still change across app restarts or status-item re-registration. Icons to the right of the marker remain visible. Command-drag affected icons back to the intended side of the marker.
