# MenuBox 1.3.0

This minor update improves menu bar toggle responsiveness and marker stability on macOS 27.

## Changes

- Keeps the tape marker registered when hidden, preserving its position instead of removing and reinserting it beside the Box icon.
- Removes the routine 250 ms delay before hiding a ready menu bar layout. Rapid reveal/hide sequences still allow a just-restored layout to settle before selecting icons.
- Coordinates the marker's layout update with icon visibility requests to reduce differences in when they appear and disappear.
- Improves rapid toggle handling and recognition of hidden markers across multiple displays, while retaining sleep/wake and display-change recovery.
- Fixes app icon generation and refreshes the bundled app icon.

## Updating

MenuBox 1.2 users can update through the app's built-in updater or Homebrew:

```sh
brew update
brew upgrade --cask elixirevo/tap/menubox
```

For manual installation, quit MenuBox and replace it in Applications with the app from the DMG for your Mac. Existing settings are retained.

Users upgrading from StatusBox 1.0 or 1.1 still need a one-time manual or Homebrew installation of MenuBox. The old updater cannot securely install builds signed with the new key. Confirm MenuBox's permissions and Launch at Login settings after migration.
