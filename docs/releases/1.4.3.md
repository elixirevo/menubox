# MenuBox 1.4.3

This update improves recovery when macOS 27 stops reporting MenuBox control identifiers, including after the system menu bar restarts.

- Resolves the box and marker when only one of the two control identifiers is available, while checking agreement across displays.
- Detects persistent missing identifiers even when both icons are still present.
- Refreshes identifiers in place before re-registering MenuBox icons. Recovery is debounced and rate-limited to avoid repeated changes to icon placement.
- Retains checks for overlapping controls, conflicting display boundaries, and ambiguous layouts.

macOS 27에서 메뉴 막대 재시작 등으로 박스·막대 식별 정보가 누락되면 접기가 계속 실패하던 문제를 개선했습니다. 식별 정보 일부가 남아 있으면 이를 검증해 사용하며, 누락이 지속되면 기존 아이콘의 정보를 먼저 복구하고 필요한 경우에만 재등록합니다.

## Known issue

The relative order of icons and the MenuBox marker can still change across MenuBox restarts or status-item re-registration. Icons to the right of the marker remain visible. Command-drag affected icons back to the intended side of the marker.

## Validation

- 180 automated tests passed; 2 conditional tests skipped.
- Replayed captured three-display failure data to verify control resolution and recovery decisions. Conflicting per-display icon placement remains rejected.
- A live forced MenuBarAgent restart with this build has not been verified.
