# MenuBox 1.4.0

This minor update improves multi-display menu bar handling on macOS 27.

## Changes

- Supports displays with different app and system-control inventories when planning and extending the hidden section.
- Recognizes MenuBox controls on secondary displays by their order, even when their distance from the display edge differs.
- Repairs persistently missing MenuBox status-item replicas while preserving the marker's hidden state, with debouncing and a cooldown.
- Anchors Box UI to the MenuBox icon on the display where it was opened.
- Rejects hiding a system control when it appears on opposite sides of the marker across displays.

여러 모니터의 메뉴 막대 아이콘 구성이 다를 때 숨김이 실패하는 문제를 수정했습니다. 특정 모니터에서 사라진 MenuBox 아이콘의 자동 복구와 Box UI 표시 위치를 개선하고, 모니터별로 막대 양쪽에 걸친 시스템 아이콘의 숨김을 방지합니다.

## Updating

MenuBox 1.2 and later users can update through the built-in updater or Homebrew:

```sh
brew update
brew upgrade --cask elixirevo/tap/menubox
```

For manual installation, quit MenuBox and replace it in Applications with the app from the DMG for your Mac. Existing settings are retained.

Users upgrading from StatusBox 1.0 or 1.1 still need a one-time manual or Homebrew installation. Confirm MenuBox's permissions and Launch at Login settings after migration.
