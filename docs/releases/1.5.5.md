# MenuBox 1.5.5

MenuBox 1.5.5 fixes hidden icons failing to return after opening System Settings → Menu Bar on macOS 27.

- Fixes visibility changes not reaching the menu bar after the Menu Bar settings pane is opened. Hiding and revealing icons continue to work while System Settings is running.
- Keeps the original hidden-app selection and recovery information until the icons have actually returned, preventing Box UI from losing its app list during a delayed restore.
- Prevents automatic hiding from replacing a pending restore with an empty selection.

macOS 27에서 **시스템 설정 → 메뉴 막대**를 연 뒤 숨김을 해제하면 앱 아이콘이 돌아오지 않던 오류를 수정했습니다.

- 표시 설정 변경이 메뉴바에 반영되도록 수정했습니다. 시스템 설정이 실행 중이어도 숨김과 해제가 정상 동작합니다.
- 실제 아이콘 복원이 확인될 때까지 기존 숨김 앱 목록과 복구 정보를 유지하여, 복원이 지연될 때 Box UI 목록이 사라지는 문제를 방지합니다.
- 복원 도중 자동 숨김이 빈 앱 목록을 저장하지 않도록 수정했습니다.

## Known issue

The relative order of icons and the MenuBox marker can still change across app restarts or status-item re-registration. Icons to the right of the marker remain visible. Command-drag affected icons back to the intended side of the marker.
