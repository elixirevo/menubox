MenuBox 개인정보 처리방침

방침 버전: 1.0
시행일: 2026-10-05

1. 운영자와 범위

MenuBox는 대한민국의 개인 운영자 elixirevo가 제공하는 무료 macOS 메뉴 막대 유틸리티입니다. 개인정보 관련 업무와 문의·권리 행사도 운영자가 담당합니다. 연락처는 elixirevo@gmail.com입니다. 앱 계정, 결제, 광고 또는 클라우드 파일 보관 서비스는 제공하지 않습니다.

이 방침은 MenuBox의 처리와 운영자가 받는 지원 문의에 적용됩니다. 현재 문서는 설정 → 도움말 및 지원 → 개인정보 처리방침에서 오프라인으로 열람·저장할 수 있습니다. 문서와 이전 변경 내역은 프로젝트 소스의 Resources에 보관합니다. 독립적인 외부 서비스의 처리에는 해당 서비스의 방침도 적용됩니다.

2. 기기 내 처리

메뉴 막대 아이콘 숨김·표시, Box UI와 메뉴 조작을 위해 실행 중인 앱의 이름·식별자·아이콘, 메뉴 막대 항목의 위치와 접근성 정보, 사용자가 여는 메뉴의 항목·제목을 Mac 안에서 처리합니다. 이러한 정보에는 타사 앱이 표시한 내용이 포함될 수 있습니다. 표시용 정보는 실행 중 메모리에서 갱신되며 앱 종료 시 해제됩니다. MenuBox는 메뉴 막대 앱 목록이나 메뉴 내용을 보고서에 첨부하지 않습니다.

macOS 27에서는 아이콘 표시 상태를 변경하고 복원하기 위해 보호된 메뉴 막대 설정을 읽고 수정합니다. 복원에 필요한 원래 값과 변경 값은 ~/Library/Application Support/MenuBox/Visibility에 임시로 저장합니다. 정상 복원이 완료되면 복원 기록을 삭제하며, 복원이 실패하면 재시도를 위해 남을 수 있습니다. 복원 전 이 기록을 삭제하면 복원에 영향을 줄 수 있습니다.

언어, 단축키, 표시 설정, 온보딩 완료, 충돌 보고 선택 등은 com.elixirevo.MenuBox 도메인의 로컬 UserDefaults에 저장합니다. 약관 동의 기록은 문서 ID·버전·제시 언어·시각·전문 SHA-256으로 구성하며 로컬에만 저장합니다. 전문 해시는 문서 식별용으로 이용자 식별번호가 아닙니다. 설정 유지와 같은 약관 버전에 대한 중복 요청 방지가 목적이며, 이용자가 로컬 기록을 삭제할 때까지 보관합니다. 일반 설정 복원은 약관 동의와 충돌 보고 선택을 지우지 않습니다.

개발용 진단 옵션을 별도로 켜면 메뉴 막대 배치·접근 상태 등의 진단 파일이 ~/Library/Application Support/MenuBox/Diagnostics에 남을 수 있습니다. 기본 실행에서 이 파일을 자동 생성하거나 외부로 보내지 않습니다. 사용자가 저장한 진단·문서 파일은 선택한 위치에 사용자가 삭제할 때까지 남습니다.

3. 권한과 로컬 자료 관리

손쉬운 사용(일부 macOS에서는 기기 제어 및 데이터 접근)은 메뉴 막대 항목을 찾고 타사 앱의 메뉴를 조작하는 데 사용합니다. macOS 27의 전체 디스크 접근은 보호된 메뉴 막대 설정을 읽고 바꾸는 데 사용합니다. 전체 디스크 접근 자체는 다른 앱의 자료에도 접근할 수 있는 넓은 권한입니다. macOS 시스템 설정에서 권한을 철회할 수 있으며 해당 기능은 제한될 수 있습니다. 권한 허용은 외부 전송 동의가 아닙니다.

운영자는 이용자의 Mac에 있는 자료를 원격으로 열람하거나 삭제하지 않습니다. 로컬 자료를 완전히 지우려면 먼저 앱을 정상 종료하여 아이콘을 복원한 후, MenuBox의 환경설정·캐시·Application Support 자료와 직접 저장한 파일을 관리해 주세요. 구체적인 삭제 지원은 이메일로 요청할 수 있습니다. 앱 파일만 삭제해도 모든 설정이 지워지는 것은 아니며, 백업·동기화 사본은 해당 도구에서 별도로 관리해야 합니다.

4. 선택적 충돌 보고

충돌 보고는 기본적으로 꺼져 있습니다. 설정 → 일반 → 진단에서 선택하며 변경은 앱을 종료하고 다시 실행한 뒤 적용됩니다. 켜진 상태에서 끄더라도 현재 실행은 종료 전까지 보고할 수 있으므로 즉시 중단하려면 앱을 종료해 주세요. 약관 동의나 이 방침의 열람은 충돌 보고 선택을 대신하지 않습니다.

켜면 오류 원인 분석과 안정성 개선을 위해 Sentry에 치명적 충돌의 예외·스택·실행 이미지 정보, 앱 버전·빌드·실행 환경, macOS·기기 관련 기술 정보와 이벤트 시각·식별자가 전송될 수 있습니다. 기본 개인정보 전송, 메모리 내부 탐색, 자동 세션·성능·네트워크 추적, 행동 기록과 일반 로그는 비활성화합니다. 전송 전 user/request/extra/tags/breadcrumbs/message/serverName 필드를 제거합니다. 이 필터가 모든 식별 가능성을 없애는 것은 아니며, 기술적인 경로·예외 내용에 개인정보가 포함될 수 있습니다. 수신 서버는 IP 주소 등 통신 정보를 처리할 수 있습니다.

전송 전 보고서는 기기의 Sentry 캐시에 남을 수 있습니다. 대기 캐시 설정의 최대 항목 수는 20이며 시간 기준의 자동 삭제 기간은 아닙니다. 보고를 끄는 동작은 이전 대기 자료를 즉시 지우지 않습니다. 나중에 다시 켜면 이전에 보고가 활성화된 실행에서 저장한 충돌이 전송될 수 있습니다.

Sentry 이벤트 보관은 발생 시 적용된 서비스 요금제에 따릅니다. Sentry의 공개 기준은 유료 요금제 90일, 무료 Developer 요금제 30일입니다. 현재 조직은 Business 기능 체험 중입니다. 서비스의 운영·보안 기록과 백업은 이벤트 조회 기간과 별개이며 Sentry의 보관 정책을 따릅니다. 보고를 끄는 것은 이미 전송된 자료의 삭제 요청과 다릅니다. 조회·삭제는 운영자 이메일로 요청할 수 있으나 특정 이용자와 보고서를 연결할 수 없는 경우 처리가 제한될 수 있습니다.

5. 업데이트와 외부 링크

Sparkle을 통해 GitHub의 elixirevo/menubox 릴리스 피드와 배포 파일에 접속합니다. 서버는 IP 주소, 요청 시각·주소와 앱/Sparkle 버전을 담은 User-Agent 등 통신 정보를 처리할 수 있습니다. 앱은 업데이트용 시스템 프로파일 전송을 기본 활성화하지 않습니다. 자동 확인은 설정 → 소프트웨어 업데이트 또는 막대 아이콘 우클릭 메뉴에서 끌 수 있습니다. 수동 확인과 다운로드도 통신을 발생시킵니다.

업데이트 제공·다운로드 및 서비스 보안이 목적이며 GitHub와 배포 CDN이 요청을 받습니다. 운영자는 이 요청의 서버 로그를 직접 보관하지 않습니다. GitHub의 보유 기준은 서비스 제공, 보안, 법적 의무 등 처리 목적에 필요한 기간이며, 모든 접속 로그의 고정 삭제 일수는 공개되어 있지 않습니다.

도움말·문제 신고 등 외부 링크는 기본 브라우저 등으로 열립니다. 해당 서비스가 쿠키·접속 정보를 처리할 수 있습니다. 앱 자체는 광고 쿠키, 표적 광고 또는 이용자 프로파일링 기능을 두지 않으며 브라우저의 GPC/DNT 신호를 별도로 처리하는 웹 서버를 운영하지 않습니다. 연결 사이트에서의 선택은 그 사이트에서 관리해 주세요.

6. 지원 문의와 공개 이슈

지원 이메일에는 이용자가 제공한 이메일 주소·이름, 문의 내용과 첨부자료가 포함될 수 있습니다. 요청한 지원과 권리 행사를 처리하기 위해 Google Gmail로 받으며 문의 해결 후 1년 이내 삭제합니다. 법적 보존 의무가 적용되면 해당 근거와 필요한 범위에 한하여 보관하며 요청 시 사유를 안내합니다. 별도의 유료 거래 기록은 수집하지 않습니다.

GitHub 이슈에 사용자가 직접 올린 계정명·내용·첨부자료는 공개됩니다. 공개 기록은 작성자 삭제 또는 운영자의 처리 전까지 남을 수 있고 다른 사람의 복사본까지 회수할 수는 없습니다. 삭제 요청은 이메일로 해 주세요. 비밀정보를 공개 이슈에 올리지 마세요. 도움말 및 지원의 진단 정보는 앱 이름·버전·빌드·macOS 버전·배포 방식이며 복사·저장만으로 전송되지 않습니다. 사용자가 직접 제출해야 수신자에게 전달됩니다.

7. 외부 서비스와 국외 처리

충돌 처리 서비스: Functional Software, Inc. (Sentry), https://sentry.io/privacy/의 문의 경로. 미국 지역 수집 엔드포인트를 사용하며 Sentry의 미국 이벤트 저장 지역은 미국 아이오와입니다. 보고가 활성화된 실행에서 충돌 자료를 HTTPS로 전송하며 목적·항목·보유 기준은 제4절과 같습니다. 보고를 선택하지 않거나 끄고 재시작하면 이후 보고 기능을 사용하지 않으며 기본 메뉴 막대 기능에는 영향이 없습니다.

배포·공개 이슈 서비스: GitHub, Inc., https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement의 문의 경로. 미국 및 서비스 운영 국가에서 처리될 수 있습니다. 업데이트 요청 시 또는 사용자가 사이트·이슈를 이용할 때 HTTPS로 전달하며 제5·6절의 목적과 기준을 적용합니다. 자동 확인을 끄고 수동 접속을 하지 않으면 앱의 업데이트 요청을 피할 수 있으나 업데이트를 받지 못합니다.

이메일 서비스: Google LLC, https://policies.google.com/privacy의 문의 경로. 지원 메일을 보내면 내용과 첨부자료가 이메일 전달 과정에서 미국 및 Google의 운영 국가에서 처리될 수 있습니다. 국가별 저장 위치는 운영자가 지정하지 않습니다. 목적은 문의 응대이며 운영자 사본은 제6절의 기간을 따릅니다. Google 자체의 운영·보안 및 백업 처리는 Google 방침에 따릅니다. 이메일 지원을 이용하지 않으면 해당 문의 전송은 발생하지 않습니다.

외부 서비스의 독립적인 운영·보안 처리와 운영자가 관리하는 충돌·지원 자료는 구분됩니다. 운영자는 앱 자료를 광고주에게 판매하거나 표적 광고 목적으로 제공하지 않습니다. 이 방침 자체는 수집·국외 이전의 포괄 동의서가 아닙니다. 별도 고지·동의 등 적용 요건이 필요한 처리에는 해당 절차가 필요하며, 약관 동의로 이를 대신하지 않습니다.

8. 파기와 보호조치

운영자가 관리하는 자료는 보유 목적이 끝나거나 정한 기간이 지나면 해당 서비스의 삭제 기능으로 삭제합니다. 서비스의 백업 사본은 각 제공자의 삭제 주기에 따르며 즉시 완전 삭제를 보장하지 않습니다. 운영자가 삭제를 위해 새 개인정보 사본을 만들지는 않습니다. 복원 기록에는 사용자 전용 파일 접근 권한을 적용하고 외부 보고·업데이트는 HTTPS를 사용합니다. 로컬 UserDefaults는 별도 암호화 금고가 아니므로 기기 계정과 백업의 보호도 필요합니다.

9. 권리 행사와 고충 처리

열람·사본, 정정·삭제, 처리정지·동의 철회와 이의신청은 elixirevo@gmail.com으로 요청할 수 있습니다. 요청 확인에 필요한 최소 정보로 본인 또는 대리인의 권한을 확인하고 적용 법령에 따라 응답합니다. 이행할 수 없는 경우 사유와 가능한 후속 절차를 안내합니다. 불필요한 신분증·비밀번호를 보내지 마세요.

10. 미국 이용자

거주 주의 법률과 운영자에 대한 적용 범위에 따라 접근·삭제·정정·이동 가능한 사본 및 이의신청 권리가 제공될 수 있습니다. 앱은 개인정보 판매, 표적 광고 목적 공유, 중대한 법적 효과를 갖는 자동 의사결정 기능을 제공하지 않습니다. 모든 주법이나 CCPA가 이 운영자에게 동일하게 적용된다고 단정하지 않으며, 해당하는 권리 요청은 제9절의 경로로 처리합니다. 권리 행사로 인해 법령에 반하는 차별을 하지 않습니다.

11. 아동·청소년

앱은 약관에 정한 성년자를 대상으로 하며 아동용 계정이나 아동 대상 광고를 제공하지 않습니다. 아동 정보의 부적절한 수집이 의심되면 운영자에게 알려 주세요. 해당 자료를 확인하여 필요한 삭제 등 조치를 취합니다.

12. 변경 안내

방침 버전·시행일과 변경 내용을 앱에 포함된 문서 및 릴리스 안내에 표시하고 이전 본문을 소스 버전 이력에 보관합니다. 새로운 처리에 추가 고지나 동의가 필요하면 시작 전에 별도로 이행합니다. 이 문서를 열람·저장하거나 방침이 변경되었다는 사실만으로 약관 재동의 또는 앱 사용 제한을 발생시키지 않습니다.
